# Gym Management System

A Gym Management System built with **ASP.NET Core MVC** to manage gym operations and member-related data using a structured layered architecture.

## Technologies

* C#
* ASP.NET Core MVC
* Entity Framework Core
* SQL Server
* LINQ
* Object-Oriented Programming (OOP)
* HTML
* CSS
* JavaScript

## Architecture

The project is organized into separate layers:

* **BLL (Business Logic Layer)** — Handles business rules and application logic.
* **DAL (Data Access Layer)** — Handles database operations and data access.
* **MVC Application** — Handles controllers, views, and user interaction.

## Features

* Gym member management
* CRUD operations
* Database integration using Entity Framework Core
* SQL Server database
* Business logic separation
* Data access layer
* MVC architecture
* LINQ queries
* Responsive web interface

## Getting Started

### Prerequisites

* .NET SDK
* SQL Server
* Visual Studio or Visual Studio Code

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Abdelmoneim-is/G-NET-02-MVC05.git
```

2. Open the solution in Visual Studio.

3. Configure the SQL Server connection string in the application configuration.

4. Apply the required Entity Framework Core migrations if needed.

5. Build and run the application.

## Purpose

This project was developed as a practical ASP.NET Core MVC project to apply **C#**, **Object-Oriented Programming**, **Entity Framework Core**, **SQL Server**, **LINQ**, and layered application architecture in a real-world style Gym Management System.
